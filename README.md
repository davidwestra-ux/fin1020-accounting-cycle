# FIN1020 Course V2

A neutral-blue GitHub Pages prototype for recreating the original
**FIN1020 Learn EveryWare: Accounting Cycle 1** website.

## Upload

Upload the complete `fin1020-course-v2` folder into the root of the existing
GitHub Pages repository.

The prototype will then be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/fin1020-course-v2/`

## Current scope

- Responsive homepage
- Project 1 overview
- Project 2 placeholder
- Resources page
- Reusable lesson template
- Source-documents lesson prototype

The original course content has not been invented or silently filled in.
Source text, images, downloads, and activities should be inserted only after
the corresponding original pages are recovered and reviewed.
