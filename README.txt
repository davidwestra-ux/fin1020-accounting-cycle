FIN1020 Accounting Cycle Website

FILES
- index.html: the complete website

HOW TO TEST
1. Open the folder.
2. Double-click index.html.
3. It should open in Chrome.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a new public GitHub repository.
2. Upload index.html to the repository.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and the root folder.
6. Save.
7. GitHub will provide a public website address.
8. Paste that address into Google Classroom.

HOW TO PUBLISH WITH NETLIFY DROP
1. Go to Netlify Drop.
2. Drag this entire folder onto the page.
3. Netlify will create a public website address.
4. Paste that address into Google Classroom.

This website is completely self-contained and does not require Moodle.
